SATU PELUK DARI JAUH

Struktur folder:
- index.html       halaman website
- css/style.css   seluruh tampilan dan animasi
- js/script.js    interaksi, navigasi, dan kontrol musik
- musik/piano.mp3 file musik milik Anda (tambahkan sendiri)

Cara menjalankan:
1. Ekstrak folder project.
2. Masukkan MP3 instrumental piano ke folder musik dan beri nama piano.mp3.
3. Buka index.html di browser.
4. Tekan tombol musik untuk memulai atau menghentikan lagu.

Catatan: gunakan musik yang Anda miliki atau punya izin untuk digunakan.
